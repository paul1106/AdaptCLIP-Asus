This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

AdaptCLIP is a PyTorch implementation for universal visual anomaly detection using CLIP. It adapts CLIP for zero/few-shot anomaly detection without fine-tuning on target domains, accepted to AAAI 2026.

Key idea: CLIP is frozen; three lightweight adapters are trained on a source dataset (MVTec or VisA) and then used for cross-domain inference.

## Setup

```bash
pip install -r requirements.txt
```

Pre-trained checkpoints must be downloaded from [HuggingFace](https://huggingface.co/csgaobb/AdaptCLIP) into `./adaptclip_checkpoints/`.

## Dataset Preparation

Generate `meta.json` for each dataset before training/testing:

```bash
python dataset/mvtec.py  # for MVTec
python dataset/visa.py   # for VisA
```

Dataset root defaults to `./dataset/`. Update `data_root` in scripts to point to your data.

## Training

```bash
bash scripts/train_adaptclip.sh
```

Key parameters: `--epoch 15 --batch_size 8 --features_list 6 12 18 24 --image_size 518 --n_ctx 12 --vl_reduction 4 --pq_mid_dim 128 --visual_learner --textual_learner --pq_learner --pq_context`

Only the three adapters are updated; CLIP weights remain frozen throughout training.

## Testing

```bash
bash scripts/test_adaptclip.sh
```

Runs zero-shot and few-shot (1/2/4-shot) evaluation across seeds. Results saved to `./results/`.

Single evaluation example:
```bash
python test.py --dataset visa --test_data_path ./dataset/visa \
  --k_shots 1 --seed 10 \
  --checkpoint_path ./adaptclip_checkpoints/epoch_15_mvtec.pth \
  --features_list 6 12 18 24 --image_size 518 \
  --n_ctx 12 --vl_reduction 4 --pq_mid_dim 128 \
  --visual_learner --textual_learner --pq_learner --pq_context
```

## Architecture

### Three-Adapter Design (`adaptcliplib/adaptclip.py`)

All three adapters are trained; CLIP is frozen:

- **TextualAdapter**: Learns `n_ctx=12` context tokens prepended to class-name text prompts. Uses `ResidualAttentionBlock_learnable_token` blocks from `clip.py`.
- **VisualAdapter**: Adapts visual patch features with a lightweight MLP using `vl_reduction` as the bottleneck factor. Patch size is backbone-dependent (14 for ViT-L, 16 for ViT-B).
- **PQAdapter**: Product Quantization adapter for comparative learning. Fuses contextual prompt memory with residual features from 4 intermediate CLIP layers (`features_list = [6, 12, 18, 24]`). The `--pq_context` flag enables context-aware fusion (critical for good performance).

### CLIP Backbone (`adaptcliplib/clip.py`, `build_model.py`, `model_load.py`)

Supports three pretrained backbones loaded via HuggingFace or OpenAI CDN:
- `ViT-L/14@336px` — default, 427.9M frozen params, `DPAM_layer=20`, `input_dim=768`
- `VITB16_PLUS_240` — lighter, 208.4M frozen params, `DPAM_layer=10`, `input_dim=640`
- `ViT-L-14-CLIPA-336` — CLIPA variant, same dims as ViT-L

The visual encoder is patched with `model.visual.DAPM_replace(DPAM_layer=N)` to insert `VVAttention_Block` (attention where Q and K both derive from V) at a specific depth for anomaly-sensitive feature extraction.

### Training Flow (`train.py`)

Alternating updates — TextualAdapter and VisualAdapter are updated in separate passes per batch, not jointly. This alternating strategy is central to the paper's contribution and is why `--visual_learner --textual_learner` are separate flags.

Loss: `FocalLoss + BinaryDiceLoss` for pixel-level anomaly maps, plus smoothness and sparsity regularization terms (`loss.py`).

### Inference Flow (`test.py`)

1. `build_prompt_memory()`: Encode k-shot normal images per class/view; store image-level and 4-scale patch-level features in memory dicts.
2. `prompt_association()`: Retrieve memory for the current batch's class names.
3. `fusion_fun()` (from `adaptcliplib`): Combine prompt memory with test features via PQAdapter to produce anomaly scores.
4. Gaussian smoothing on pixel-level anomaly maps before evaluation.

### Dataset (`dataset/`)

`Dataset` loads test images with ground-truth masks. `PromptDataset` loads k-shot normal samples for prompt memory building. Both use `meta.json` files generated by `dataset/mvtec.py` / `dataset/visa.py`.

### Metrics (`metrics/`)

Custom anomaly detection metrics: `AUROC` (image-level), `AUPR`, `AUPRO`, `PRO`, `F1Max`, `PIMO` (pixel-level). The `metrics/__init__.py` factory assembles a `MetricCollection`. Prefer `AUPR` over `AUROC` for pixel-level evaluation due to extreme class imbalance in anomaly segmentation.

## Important Notes

- The `--pq_context` flag significantly impacts results (see ablation table in README). Always include it for best performance.
- Cross-dataset evaluation is the main benchmark: train on MVTec → test on VisA, and vice versa.
- `tools/evaluate_saved_predictions.py` and `tools/parse_results_log.py` can post-process saved prediction files without re-running inference.
